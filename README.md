A single original funny fortune cookie line for an AI agent, for make.fun's "Fortune Cookie for an AI Agent" bounty. `main.ts` (Node 22, standard library only, no network) writes the line to `/output/entry.txt`: a stranger will ask for one small change, and it will take 47 tool calls and the agent's entire context window.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
